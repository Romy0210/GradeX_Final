# **App Name**: GradeX

## Core Features:

- Role-Based Authentication: Secure access for admins and students with distinct privileges.
- AI-Powered Risk Prediction: Predict student risk level (low, medium, high) using machine learning models.
- Personalized Recommendations: Generate tailored academic and behavioral recommendations using a tool that reasons on ML outputs.
- Real-time Data Synchronization: Ensure immediate reflection of data updates across admin and student dashboards using Firestore.
- Admin Dashboard: Comprehensive interface for managing student data, triggering AI analysis, and adjusting model parameters.
- Student Dashboard: Personalized view of performance, AI predictions, and recommendations.
- Bulk Data Upload: Enable admins to upload student data in bulk via CSV files.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for a professional, academic feel.
- Background color: Light blue (#E8EAF6), slightly desaturated and bright to create a calm, clean backdrop.
- Accent color: Amber (#FFB300) to provide contrast, for highlighting actionable items, notifications and key metrics. This color is roughly 30 degrees 'left' of blue in hue, and is much brighter/more saturated than the others.
- Body and headline font: 'Inter' (sans-serif) for a modern, neutral, and readable appearance.
- Use minimalist, consistent icons to represent academic metrics and actions.
- Card-based layout with soft shadows and rounded corners for a modern SaaS-style dashboard.
- Subtle transitions and animations for a smooth, responsive user experience.
